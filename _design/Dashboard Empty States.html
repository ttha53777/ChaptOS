Dashboard · empty states

Three kinds of nothing.

A new org's first frame is a wall of confident zeros — 0.0% attendance, $0 dues, 0.00 GPA — four numbers nobody measured, set in the same face and size as real data. Meanwhile “Nothing needs attention — nice work.” congratulates a founder who has done nothing yet. Nothing here computes wrong. The dashboard just has one vocabulary for emptiness and three different situations to express.

Kind 01

Unset

Never configured. No records exist and none are coming until someone acts.

Invite — name the one next move.

Kind 02

Unstarted

Set up correctly, but the period hasn't produced data yet. Waiting is the right answer.

Orient — say when it fills.

Kind 03

All clear

Real data behind it, and genuinely nothing wrong. The only kind that has earned praise.

Affirm — and mean it.

01
Never print a number you didn't measure.An empty record set is an em-dash, not 0.0%. The Treasury tile already does this — it becomes the standard, not the exception.
02
The note carries the reason, not the statistic.“0 below 80%” is noise at zero. Replace it with a why, plus at most one action.
03
Praise requires evidence.Every affirming string gates behind “there was data to be fine about.”
04
Empty chrome recedes.No search box over nothing, no gold PINNED chip on a placeholder, no “Showing 0 of 0”, no inert click target.
05
Offer an action only to someone who can do it.Swap the copy, don't hide the block — the pattern already set by the events and docs pages.
06
Empty is not loading.The Treasury rail presents a slow fetch as “No transactions yet.” A pending answer is not a wrong one.
