Same shape as Fundraising

  • Title with one highlighted phrase: "Your links, all in one place" (Fundraising says "Fundraising, the easy way").
  • One plain sentence about what you do here. No "reference library" and no AI digest on an empty page.
  • One dashed card with three pictures: paste a link → give it a name → everyone can open it.
  • One button. Members get a single line instead.

What's real

  • The button opens the same Add form that exists today (DocForm: name and link) and saves through POST /api/docs.
  • The kind shown under the link uses the same rules as kindOf() in docs/lib.tsx.
  • Shows when there are no docs and no folders, the same check as today's empty box. After that, the normal page takes over.
