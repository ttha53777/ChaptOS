Scene A · the first frame. A greeting, one question, one button. Nothing else — no tabs to a page that has no content, no four-item feature list, no zeroed instruments. A first-time user should have exactly one thing to do and no decisions to make.

The question is the opening balance because app/[slug]/page.tsx:1322 already treats a set openingBalance as proof the books are open, independent of transaction count — and because it's the only number a new treasurer reliably knows: whatever is in the account right now. Everything the old version explained up front ("what this turns on", naming category streams) either waits until after, or is one quiet line at the bottom.

Next you'll name your income and expense categories — then you can log transactions, assign dues, approve reimbursements, and export a semester report for the transition binder.

Scene B · name the money. The second (and last) step: what the chapter's income and expenses are actually called. Two books side by side, one row per category, and an inline add that behaves like typing the next line of a list — no dialog, no color-picker ceremony. Reorder by dragging; the order is the picker order and the donut's legend order.

This is backed by a real shipped table — TransactionCategory, 2026-08-08 — so the mock obeys its rules instead of inventing new ones. slug is the string the ledger already stores and is immutable, so the pencil renames the label only and every past transaction keeps resolving. builtin means reserved, not "seeded": only Dues and Reimbursement carry it, because the app writes to those slugs itself — renameable, never deletable. And a used category is archived (hidden), not deleted, so its history still resolves; delete is only offered for one that never got used.

Seeds shown are the real DEFAULT_CATEGORY_SEEDS with dusk hexes from the per-book palettes (income starts green, expenses start clay) so two new streams never land the same dot.

Scene C · the second kind of nothing. The books are open — there is a real balance, typed by a human — but no transactions exist yet. This is the state the current page can't distinguish from "broke", and it's the one a chapter sits in for days.

Balance is now a real number in full ink; Income and Expenses stay em-dashes, because nothing has moved. No praise, no confetti — the banner just names the next action. Note the tabs are live now and New txn is enabled.
